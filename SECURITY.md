# Security

Please report a security problem privately rather than in a public issue.

Use **Report a vulnerability** on this repository's **Security** tab. Say what you found, how to
reproduce it and which version of the extension you saw it in. You should get a reply within a week.

## Scope

The code in this repository and the extension published from it to the Visual Studio Marketplace
by `adam-wheater`.

## How the extension handles your data

The extension runs entirely in your browser, inside Azure DevOps. It has no backend and no
telemetry. The README's **Privacy** and **Scopes & permissions** sections list exactly what it
reads, what it stores and which hosts it talks to.
